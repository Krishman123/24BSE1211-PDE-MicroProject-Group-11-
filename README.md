## Project Summary
This micro-project focuses on the application of Partial Differential Equations in quantum confinement using the one-dimensional time-dependent Schrodinger equation.
A particle confined in a one-dimensional infinite potential well is considered. The method of separation of variables is used to obtain the quantized energy states and the corresponding wave functions.
The analytical solution is implemented using python in google colab. Numpy and Matplotlib are used to calculate and visualize the probability density for the first three energy levels(n=1,2,3).
